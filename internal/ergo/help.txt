{{BOLD}}ergo{{RESET}} — a local, dependency-aware backlog for coding agents.

Ergo keeps a backlog in the repository so agents and humans can share it across
sessions. Tasks are stateful and can depend on one another. A task is ready
when its dependencies are complete. A task with children is an epic; the epic
completes when its children finish.

{{HEADER}}USAGE{{RESET}}
  ergo [global flags] <command> [args]

{{HEADER}}WORKFLOW{{RESET}}
  {{CMD}}ergo init{{RESET}}
  {{CMD}}ergo new task "Add login"                 # returns task ID ABCDEF{{RESET}}
  {{CMD}}ergo list --ready                         # shows available work{{RESET}}
  {{CMD}}ergo claim ABCDEF --agent model@host{{RESET}}
  {{CMD}}ergo done ABCDEF -m "Implemented and verified"{{RESET}}

{{HEADER}}COMMANDS{{RESET}}
  init [dir]                                  initialize an Ergo backlog
  new task "<title>" [--epic <id>]            create a task; optional stdin sets its body
  new epic "<title>" --file <path>            create an epic and tasks; optional stdin sets epic body
  list [--epic <id>] [--ready | --all]        list work
  show <id> [--body]                          show a task or epic, or only its body
  claim [<id>] --agent <identity>             claim chosen or ready work
  done <id> [-m <text>] [--result <path>]     complete a task
  block <id> [-m <text>] [--result <path>]    record an impediment
  cancel <id> [-m <text>] [--result <path>]   cancel a task
  release <id> [-m <text>] [--result <path>]  return unfinished work to todo
  title <id> <title>                          replace a title
  body <id>                                   replace a body from stdin
  move <id> <epic-id>                         move a task into an epic
  move <id> --root                            move a task to the root
  sequence <A> <B> [<C>...]                   require A before B before C
  unsequence <A> <B> [<C>...]                 remove that order
  where                                       print the active .ergo path
  prune [--yes]                               preview or apply pruning
  compact                                     compact the event log
  quickstart                                  print the complete guide
  version                                     print the build version

{{HEADER}}GLOBAL FLAGS{{RESET}}
  --dir <path>        start discovery at this path or .ergo directory
  -h, --help          print help
  -V, --version       print the build version
